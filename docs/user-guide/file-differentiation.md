# File Differentiation

LextEdit includes **SyntaxDiff**, a file comparison tool for quickly identifying differences between two files or two versions of the same content.

## Opening SyntaxDiff

SyntaxDiff can be triggered from the main LextEdit window to compare between executions or revisions of a file.

## Display Modes

### Side-by-Side (Left-to-Right)

Both files are displayed in parallel columns with a separator control in the middle. Differences are highlighted with distinct colors. Click the separator control between a changed pair to apply or revert the change from one side to the other.

### Top-and-Bottom (Left-above-Right)

One file is shown above the other. Useful when working with long lines that are difficult to compare side by side.

## Navigation

- **Colored bookmarks** — jump directly to the next or previous change
- Click any change in the separator area to apply it between files

## Additional Options

- **Ignore whitespace** — differences that are only whitespace are excluded from the comparison
- **Ignore case** — case differences are ignored
- **Line numbering** — optionally display line numbers in both panes
- **Drag and drop** — drag files directly into either comparison pane to load them
- **Syntax colorization** — both panes support grammatical colorization for 20+ languages, making code-level differences easier to read
