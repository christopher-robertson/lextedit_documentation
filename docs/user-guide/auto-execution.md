# Auto Execution

The **Auto Execution** feature allows LextEdit to automatically run a command multiple times, stopping when a defined condition is met.

## Accessing Auto Execution

Go to **File → Auto-Execute** to open the Auto Execution configuration.

## How It Works

Auto Execution is useful for:

- Polling a system until a specific result appears
- Running repeated checks during testing or development
- Automating multi-step processes where each step depends on the previous result

Configure the command to execute, the repeat interval, and the stop condition. LextEdit will continue executing the command at the specified interval until the stop condition is satisfied.
