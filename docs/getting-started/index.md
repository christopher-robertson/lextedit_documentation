# Getting Started

This section guides you through installing LextEdit and getting up and running quickly.

| Page | Description |
|---|---|

## Prerequisites

- Windows operating system
- Network access to a MOCA/MSQL server, or a configured ODBC data source
- (Optional) Microsoft Excel or Access, for ODBC-based connections
