# Keyboard Shortcuts

## LextEdit (Main Window)

| Shortcut | Action |
|---|---|
| `Ctrl+O` | Open a file |
| `Ctrl+S` | Save the current file |
| `F8` | Open the Connection Information window |
| `Ctrl+Enter` | Execute the current command context |
| `Ctrl+Shift+Enter` | Execute the selected text only |
| `Ctrl+Alt+Enter` | Execute the entire script |
| `F6` | Quick save grid results to a LextEdit file |
| `F5` | Export grid results to Microsoft Excel |
| `Alt+F4` | Exit the application |
| `Ctrl+Shift+U` | Uppercase selected text (preserves string literals) |
| `Ctrl+U` | Lowercase selected text (preserves string literals) |
| `Ctrl+Alt+F` | Format the current editor content |
| `Ctrl+H` | Open the History Navigation window |
| `Ctrl+L` | Open the Component Lookup window |
| `Ctrl+E` | Open an Explain Query on selected text |
| `Ctrl+T` | Open the Trace Profiler |
| `F9` | Start a MOCA trace (default profile name) |
| `Ctrl+F9` | Start a MOCA trace (prompt for profile name) |
| `Ctrl+P` | Open the Application Preferences window |
| `Ctrl+F` | Open the Find and Replace window |
| `F3` | Find next |
| `Shift+F3` | Find previous |
| `Ctrl+Alt+Up` | Scroll to previous history item (without opening history window) |
| `Ctrl+Alt+Down` | Scroll to next history item (without opening history window) |

---

## Component Lookup Window

| Shortcut | Action |
|---|---|
| `Ctrl+D` | Look up the selected text as a command name |
| `Ctrl+Alt+F` | Format the text in the Component Lookup window |
| `Ctrl+F` | Open the Find and Replace window |

---

## Trace Profiler Window

| Shortcut | Action |
|---|---|
| `F5` | Reopen the current trace file (refresh) |
| `Ctrl+O` | Open a remote trace file from a MOCA connection |
| `Ctrl+L` | Open a locally saved trace file |
| `F8` | Open the Connection Information window |
| `Ctrl+S` | Save the current trace file locally |
| `F10` | Open a LextEdit window |
| `Ctrl+E` | Open a blank Explain Query window |
