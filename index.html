    LextEdit Documentation

    LextEdit is a development tool for database systems built by Orbital Services. It combines a powerful file editor, a semantic parser for over 20 programming languages, and the ability to execute SQL and MOCA commands and display results in a usable data grid.

    LextEdit is built by developers who use it daily on real warehouse management and logistics systems. Every feature reflects actual development workflow needs, making it a practical and dependable tool for both experienced and new developers working in MOCA/SQL environments.

    What LextEdit Does

    • File editing: open, edit, and save files locally with syntax colorization for 20+ languages. LextEdit supports grammatical and semantic parsing, so colorization reflects actual code structure rather than simple keyword matching.
    • Database connectivity: connect to MOCA/MSQL systems and ODBC data sources, including Microsoft Excel and Access databases. Connections can be secured and distributed to team members without exposing credentials.
    • Query execution: run SQL and MOCA commands and view results in an interactive grid. The grid supports copying results as WHERE clauses, INSERT statements, or CSV data for downstream use.
    • Trace profiling: open and analyze MOCA trace files with a structured tree view. The TraceProfiler organizes trace output by command and sub-command, making it easy to navigate deep execution flows.
    • File differencing: compare two files side-by-side using the SyntaxDiff tool. Both panes support syntax colorization and inline change application.

    LextEdit is designed by developers who use it daily. Features are driven by real-world usage, making it a solid and practical development tool.
